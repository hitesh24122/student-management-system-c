# Student Management System in C

## Project Description

The **Student Management System** is a console-based application developed using the C programming language. This project is designed to manage basic student information efficiently through a simple and interactive menu-driven interface.

The main objective of this project is to apply fundamental C programming concepts to solve a practical problem. It allows users to enter student information, display stored records, find students with the highest and lowest marks, calculate average marks, and search for specific students using their roll numbers.

The application uses structures to organize student information, arrays to store multiple student records, loops to perform repeated operations, and conditional statements to manage different menu options.

This project was developed as part of my C programming learning journey to strengthen my understanding of problem-solving, logical thinking, data structures, and program execution.

## Key Features

**1. Add Student Details**

Users can enter student information, including name, roll number, and marks. The program supports storing up to 100 student records during execution.

**2. Display All Students**

Displays the information of all students currently stored in the application.

**3. Find Highest Marks**

Identifies the student with the highest marks and displays their name, roll number, and marks.

**4. Find Lowest Marks**

Finds the student with the lowest marks using comparison logic.

**5. Calculate Average Marks**

Calculates the average marks of all entered students.

**6. Search Student by Roll Number**

Allows users to search for a student by entering their roll number. If the student is found, their details are displayed. Otherwise, an appropriate message is shown.

**7. Interactive Menu System**

Uses a continuous loop to display the menu, allowing users to perform multiple operations without restarting the application.

## Project Limitations

Currently, student records are stored in memory and are lost when the application closes. The system supports a maximum of 100 students and does not include permanent file storage, student record editing, or deletion features.
